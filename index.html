Festival and day events

Full inline embed

The simplest and most common shape. Drop the widget straight into the page, below your line-up or your gallery, and the buyer never leaves. Best when ticketing is the main reason people visit the page, and when you have more than one ticket type to show off.

yourdomain.com/tickets

When to use it

  • Tickets are the point of the page.
  • You have several tiers and want them all visible at once.
  • You want the buyer to compare ticket types without a click.

Watch for

  • Give it real height. Squeezing the widget into a short box creates a scrollbar inside a scrollbar, which is the fastest way to lose a mobile buyer.

Conferences

Register, then buy

Conferences usually need to know who is coming before taking their money: job title, organisation, dietary needs, which track they want, whether they qualify for the member rate. Turn on the Quicket registration form and the buyer completes it inside the same embed, before any ticket is released.

You can approve each registrant manually, or let approval happen automatically. Manual approval is how you run an invitation-only or vetted event without maintaining a separate list anywhere.

yourdomain.com/attend

What this replaces

  • A separate registration form, then a spreadsheet, then a list of discount codes emailed out one by one.
  • Approval is the gate, so no per-person code is needed at all.

Set it up

  • Event dashboard, then Manage Checkout, then Registrations.
  • Set approval to manual, add your questions, and set the window with registrations open from and open until.
  • Turn on Force registration for all ticket holders if every named attendee must complete the form, not just the buyer.

Sports fixtures

One embed per fixture

A season is many events, not one. Give each fixture its own embed and switch between them with tabs, so a supporter lands on your fixtures page and buys for the match they actually want without leaving it. Each tab loads only when it is opened, so the page stays fast however many fixtures you add.

yourdomain.com/fixtures

If your fixtures are one event with several dates rather than separate events, use time slots instead of tabs. One embed then shows a date picker and handles the whole run on its own.

Concerts and club nights

Buy in a pop-up

When the page is doing work that the ticket box would interrupt, a full-bleed artist image, a video, a scrolling line-up, put the checkout behind a button instead. The widget opens over the page and closes back to the exact spot the buyer was in. The embed only loads when the button is pressed.

When to use it

  • The page is visual and a ticket widget would break the design.
  • You want one clear call to action rather than a list of tiers.
  • You are putting the same button in several places on one long page.

Watch for

  • On a phone the pop-up needs near full height, or the buyer ends up scrolling a small box inside a small screen.

Theatre and seated events

Deep link to seat map

This is the one case where embedding is usually the wrong answer, and saying so is more useful than pretending otherwise. A seating chart needs width and precision. Inside a narrow column on someone else's page it becomes hard to use, especially on a phone.

Send the buyer straight to the seat map on the full page instead. Style the button as your own and the handover is barely noticed, and they get a seat picker that actually works.

The honest rule

  • Embed when the buyer is choosing a ticket type. Link out when they are choosing a physical position.
  • A link that works beats an embed that frustrates.

Keep the thread

  • Open it in a new tab so your page stays behind it.
  • Use a link campaign so the sale is still attributed to your site.

Marathons and mass participation

Embed plus offline entry

Runs, rides and mass entry events collect far more than a name: category, distance, age, emergency contact, shirt size, club. All of that goes in the registration form and comes back in one export, so bibs and categories are sorted before race day.

These events also reach people who will never complete a web checkout. An entrant with no data bundle is still an entrant, so the same event can take entries over USSD on a mobile menu, with payment by mobile money. The embed and the offline channel feed the same entry list.

yourdomain.com/enter

Collect once, use everywhere

  • Registration questions carry through to the entry export, the check-in report and the bib list.
  • Set purchase limits per entrant so one person cannot take a hundred places.
  • Ticket groups keep 5km, 10km, 21km and 42km tidy rather than a wall of options.

Reaching everyone

  • Ask us about USSD entry if a meaningful share of your field is not buying online.

Community and free events

RSVP embed

Free entry costs nothing in commission, so there is no reason to run a free event on a form and a spreadsheet. Use the same embed for RSVPs and you get a real guest list, a working scan at the door, and a way to message everyone who said they were coming.

yourdomain.com/rsvp

Why not a form

  • A form gives you a list of names. This gives you a scannable ticket and an accurate head count on the night.
  • Capacity is enforced, so you cannot accidentally take more RSVPs than the room holds.
  • No commission on free tickets.

Private, members and pre-sale

Access code unlock

Hide a ticket type so it does not appear to the public, then release it with an access code. The embed sits on your page looking like a normal ticket box, and only the people holding the code see the hidden tier. Use it for members, sponsors, guest lists and pre-sale windows.

yourdomain.com/members

Two ways to run it

  • One shared code for a whole group, simple to distribute and fine when leakage does not matter.
  • Unique single-use codes per person, imported as a CSV with code, numuses and listname columns.

Pre-sale windows

  • Pair an access code with a sales window so the members tier closes automatically when general sale opens.

Getting your own embed code

Four steps, no developer needed.

1
Open your event

Organiser Hub, then My Events, then click your event name.

2
Go to the widget

Settings, then Integrations, then Widget.

3
Match your colours

Use the colour picker or paste your hex codes. Click Save Changes before copying, or your colours will not carry across.

4
Paste the iFrame

Copy the code and drop it into your page wherever the ticket box should appear.

What the code looks like. Only two values change between events, the product id and the product name.

<iframe
  src="https://www.quicket.co.ug/embed.aspx?productid=384462&productname=your-event-slug&embed=true&v=2"
  frameborder="0" scrolling="yes" width="100%" height="800">
</iframe>

Use quicket.co.ug for Uganda and quicket.co.ke for Kenya. Keep width="100%" so it adapts to your layout, and give height enough room that the widget does not scroll inside itself.
